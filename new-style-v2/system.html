(01)

Signals

Lead gen 4h
Challenge

Hunting and sorting buyers manually burns time and still misses live pain signals.

Solution

Semi-automated workflows watch permits, queues, and expansion signals, then hand a person a reviewed list.

Result

A filtered company list ready for human judgment. Never auto-contacted.

Find companies with a reason to act, not names on a list.

A new data center permit is a live pain signal. I build fit-for-purpose, semi-automated workflows around whatever signal matters: construction permits, interconnection queues, grid modernization programs, plant expansions. Anything that says someone will soon need switchgear, transformers, or energy storage.

The workflow collects the companies behind each signal, separates buyers from noise, and hands a person a reviewed list. It never contacts anyone on its own.

(02)

Enrichment

Leads, first pull 143
Challenge

Maximize what every lead is worth: no time burned on low-quality leads, and no high-quality lead wasted on a generic approach.

Solution

Enrichment turns companies into known people with personal context... automatically.

Result

A personalized package for every single lead: emails, call scripts, LinkedIn requests, all grounded in who they are.

Turn each signal into people worth talking to.

Every lead list goes through the same funnel, whatever signal created it. From the first pull: 132 companies surfaced → 42 matched the ideal customer profile → an average of 3.4 relevant people at each → about 143 real leads, each one a named person with a reason to hear from us.

The tooling: Sales Navigator to find the people who best match the target persona, Clay to enrich each one with context from their LinkedIn presence and company, Apollo and similar tools for verified email addresses and phone numbers.

What every lead package contains

Why this company: the signal that surfaced it and how well it fits the profile.

Why this person: role, seniority, and their likely distance from the pain.

Ready to use: a personalized opener, email content, call script, and LinkedIn request... generated automatically, per lead.

Outreach

Channels 3
Challenge

Outreach has to convert... and it has to keep working when the group tests a new strategy, a new market, or a new end-to-end combination.

Solution

Personalized LinkedIn, email, and call scripts from the same CRM evidence, with a human deciding the next touch.

Result

Turn enriched context into a human-led multi-touch workflow.

Each enriched list becomes a full workflow: personalized LinkedIn touches, emails, and call scripts, all starting from the same signal, person, and likely pain.

Execution is semi-automated on purpose. Replies, objections, and even silence are how you learn whether a new market or a new combined offer is landing. Full automation optimizes that learning away. The system carries the research; the salesperson carries the relationship.

Use case: the perfect-fit document

Each lead receives a use-case document that reads like it was written for exactly their problem... because it was. Assembled from approved reusable blocks plus sections built for that person, that company, that pain. A perfect fit that never feels like a mail merge.

The rails beneath every stage

Design system and guardrails

(01)

The brand is code, not a paragraph

CSS tokens for colors and type. Reusable HTML patterns. Rule files the agent must load before producing anything visual. Repeatable rendering and export. The constraints live in the files, so the output cannot casually drift. This is why your prose-instruction design system made things worse and this one doesn't.

(02)

Every claim keeps its receipts

Stats and quotes are tagged by provenance and publication status. Pre-send checks block unsupported claims and sensitive material. Feedback becomes a permanent rule, so the same correction does not return wearing a new hat. And every proof point carries its ICP era, because I learned in a pivot that old evidence can poison a new story.

The practical difference

When something changes

Today, when something changes

Strategy changes → you remember which assets exist → people search folders → several files get missed → reps keep old copies → the next change starts the scavenger hunt again.

With the living system

Strategy changes → source objects update → affected assets appear in a review queue → the right owners approve → updated views publish → sales receives the release → old versions retire.

This pitch already ran that workflow manually. One strategic insight changed the source model, which forced updates to the extraction, the inventory, the mapping, the narrative, and the site you're reading. The Ampere build turns that discipline into an operating system.
