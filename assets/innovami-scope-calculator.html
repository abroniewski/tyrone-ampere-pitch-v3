KEY MODELLING NOTES
• EFFORT vs CALENDAR are decoupled. Effort (man-days) sets COST and never changes with client speed (except the small rework premium). CALENDAR (elapsed months) is a separate output driven by capacity + flow efficiency — this is the 6/9/12-month spread.
• Connectors are SELF-HOSTED Airbyte + custom CDK builds. No monthly connector subscription. The work is one-off BUILD EFFORT, already inside WP effort. Only ongoing recurring cost is the Konekti license + LLM usage.
• LLM API usage (OpenAI/Anthropic/Gemini, client-cloud-hosted) is a pass-through, still being defined. NOT in totals.

HOW TO USE THIS: the COST (block A) is what you quote and what it costs you to deliver — it barely moves with client speed. The CALENDAR (block B) is the timeline COMMITMENT — that's what flexes 6->9->12 months on client responsiveness. Quote a fixed price band off block A; commit to a timeline RANGE off block B, with a clause that elapsed time assumes agreed client response SLAs (access, answers, approvals).

WHY THIS ORDER: the metrics have a natural dependency chain that also matches data-source readiness. CPL/CPA need only spend + lead counts (fast). CAC adds won-deal linkage. Channel->revenue needs identity resolution (hard). LTV:CAC needs realised revenue (deepest). So sequencing by fastest-metric-to-value ALSO builds the end-to-end funnel in the only order the data allows — no conflict between 'quick wins' and 'full picture'.
