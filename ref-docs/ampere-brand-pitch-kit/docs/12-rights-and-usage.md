# 12. Rights and Usage

## Intended use

This kit is designed for a private pitch, prototype, or internal review. It demonstrates how new marketing content could live inside a design language that is recognizably aligned with Ampere Alliance.

## What this package owns

The package includes original:

- HTML, CSS, and JavaScript.
- Pitch copy.
- Abstract SVG artwork.
- Component specifications.
- Design-token implementation.
- Motion implementation.
- Concept mark.

The concept mark is not an official company asset and must not be presented as one.

## What is not bundled

The package intentionally excludes:

- Official Ampere logo files.
- Official portfolio-company logo files.
- Official website source code.
- Official font files.
- Staff and leadership photography.
- Portfolio photography and video.
- Agency case-study screenshots.
- Copied page copy.
- Private performance data.

## Before public launch

Obtain written approval or a valid license for:

1. Company and portfolio logos.
2. Photography and video.
3. Fonts.
4. Testimonials and attributed quotes.
5. Performance claims and statistics.
6. Press logos and excerpts.
7. Maps and third-party data.
8. Any official copy carried over from the current site.

## Trademark handling

- Use Ampere Alliance's name only in an accurate, nonconfusing context.
- Do not alter the official mark.
- Do not imply that the concept has been approved when it has not.
- Keep the `Pitch concept` qualifier visible during external review.
- Remove the qualifier only after approval and handoff.

## Design-system emulation boundary

It is generally safer to recreate broad visual principles, layout logic, spacing behavior, and interaction patterns in original code than to copy source code or redistribute protected assets. This package follows that boundary.

A public site should also contain enough original content and implementation detail that it is not a deceptive clone.

## Claims and numbers

Every public number needs:

- An owner.
- A source.
- A date range.
- A definition.
- Approval for publication.

Do not use placeholder numbers as real claims.

## Review gates

### Gate 1: Concept review

- Brand resemblance.
- Message direction.
- Page flow.
- Initial content plan.

### Gate 2: Asset approval

- Logos.
- Photography.
- Fonts.
- Quotes.
- Data.

### Gate 3: Legal and communications approval

- Claims.
- Privacy.
- Terms.
- Accessibility statement.
- Tracking and consent.

### Gate 4: Launch approval

- Final visual comparison.
- Mobile QA.
- Performance.
- Form routing.
- Analytics.
- Search metadata.

## Practical pitch use

For a private presentation, keep a small note in the footer or opening screen stating that the work is an unofficial concept prepared for Ampere Alliance. This protects clarity without weakening the pitch.
