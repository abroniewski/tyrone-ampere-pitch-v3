## Confidence scale

- **High**: directly visible in public case-study imagery or current indexed architecture.
- **Medium**: repeated visual evidence with implementation values estimated from proportions or sampling.
- **Low**: plausible reconstruction that needs direct current-site comparison or approved source files.

## Quality standard

Call the result brand-faithful when:

- The dominant composition, type behavior, color balance, geometry, and interaction character align.
- The page remains original in content and code.
- Approved assets replace placeholders.

Call it pixel-matched only after completing `14-calibration-protocol.md` against current official screenshots and recordings.
