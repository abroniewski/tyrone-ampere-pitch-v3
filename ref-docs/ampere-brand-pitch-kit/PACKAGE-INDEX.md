## Use these to build

- `assets/css/tokens.css`: color, typography, spacing, layout, and motion controls.
- `assets/css/base.css`: global reset, themes, grids, and reveal primitives.
- `assets/css/components.css`: all component and responsive styling.
- `assets/js/app.js`: preloader, navigation, reveal, parallax, counters, and magnetic actions.
- `build_site.py`: shared templates and prototype content.
- `data/design-tokens.json`: machine-readable design controls.
- `data/component-registry.json`: component anatomy, variants, states, motion, and accessibility.
- `data/content-model.json`: page and CMS content architecture.
