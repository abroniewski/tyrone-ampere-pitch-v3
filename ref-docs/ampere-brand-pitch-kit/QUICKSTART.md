# Quick Start

## Fastest route to a client-ready pitch

1. Replace the concept wordmark in `build_site.py` with an approved Ampere SVG mark.
2. Replace the three campaign SVG fields with approved photography or campaign renders.
3. Update the hero and section copy in `build_site.py`.
4. Run `python3 build_site.py` to regenerate all pages.
5. Check desktop at 1440 x 900 and mobile at 390 x 844.
6. Review motion with reduced-motion enabled.
7. Run the rights and launch checklist in `docs/12-rights-and-usage.md`.

## High-impact token edits

Change these first in `assets/css/tokens.css`:

- `--color-electric`
- `--font-display`
- `--type-hero`
- `--gutter`
- `--section-space`
- `--duration-reveal`

## Keep these design rules intact

- No rounded cards or pill-heavy UI.
- Use one-pixel rules instead of shadows.
- Keep headlines thin, large, and deliberately line-broken.
- Use blue for decisive actions, numbers, and state changes.
- Reserve angled geometry for hero media, campaigns, and major CTAs.
- Let sections breathe. Do not compress the vertical rhythm.
